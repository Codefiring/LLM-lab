
You are a systems analyst at an urban traffic control center preparing to integrate
AI agents into smart intersections. The city wants to optimize traffic flow while
reducing accidents and emissions. Your job is to classify three proposed agents -
Sensor Agent (real-time data collector), Traffic Light Controller (actuator), and
Route Planner (navigator) - into correct agent types, map their interactions, and
explain why this classification matters for city performance.

Review the Agent Types
Skim the reference table of AI agent types (reactive, deliberative, hybrid).
Outcome: Ready to classify based on key attributes.

Classify the Agents
Decide which type each proposed agent belongs to (justify in one
sentence each).
Outcome: Table with agent name, type, and short justification.

Map the Interactions
Use a diagram tool to create a simple flow: how data moves from Sensor
Agent → Traffic Light Controller → Route Planner and back (if feedback
loop exists).
Annotate arrows with short labels (e.g., “traffic data,”
“control command”).
Outcome: Interaction diagram.

Analyze Implications
Write 100–150 words on: How does using reactive vs deliberative agents
affect speed, accuracy, and system resilience?
Outcome: Short write-up highlighting trade-offs.


Question Prompt: "Upload your classified agent table and interaction
diagram showing agent roles and data flow."

Question Prompt: "Briefly describe how you decided on each classification
(mention key attributes you used), your reasoning"

Question Prompt: "Explain in 100–150 words how the choice of agent types
affects speed, scalability, and decision quality in your traffic system."

Question Prompt: "In a few sentences describe, what surprised you about
classifying and mapping these agents, and what would you do differently in a
real deployment?"



Specificity: Use agent type names explicitly (Reactive, Deliberative, Hybrid).
Clarity: Diagrams must have labeled nodes and arrows — AI grading looks for
connectivity.
Depth: Go beyond surface-level by discussing trade-offs (e.g., "reactive agents
are fast but brittle").
Progression: Submit diagram first, then reasoning and reflection.
